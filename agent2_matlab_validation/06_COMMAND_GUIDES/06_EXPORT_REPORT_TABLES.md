# Export Report Tables

Use small Markdown or CSV tables for the final report pack.

## Available table families
- S8-S11 summary table
- Phase2A live DB summary table
- event marker summary table
- energy summary table
- MATLAB validation pass/fail table

## Recommended approach
- Export Markdown when the table is meant for direct report insertion.
- Export CSV only if the table will be re-imported into MATLAB.
- Keep the exported table set small and readable.

## Preferred report folders
- `05_SELECTED_TABLES`
- `07_REPORT_TEXT`
