# Safe GitHub Export

## Safe to Push
- MATLAB validation reports
- selected lightweight PNG figures
- selected CSV or Markdown summary tables
- MATLAB command guides
- README files

## Do Not Push
- password files
- large raw exports
- temporary MATLAB files
- large figure folders
- database dumps
- logs
- credentials

## Final Note
Only export the curated demo pack. Keep bulky output folders in quarantine or leave them in the original workspace.
